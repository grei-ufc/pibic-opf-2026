# pibic-opf-2026

Este repositório tem como objetivo armazenar e organizar informações relevantes
sobre o projeto desenvolvido para o PIBIC 2026, que tem como tema "Otimização de
Problemas de Fluxo de Potência (OPF) em Sistemas de Energia Elétrica". O projeto
busca explorar técnicas avançadas de otimização para melhorar a eficiência e a
confiabilidade dos sistemas elétricos, contribuindo para o avanço da pesquisa na
área de engenharia elétrica.
