### 2. Estudo da Linguagem Julia e JuMP
Reli o site recomendado pelo professor para entender a linguagem Julia e suas principais vantagens quanto a outras linguagens. Parece bem simples por ser de alto nível, mas a principal parte do estudo foi sobre **JumMP**. Pelo que eu entendi, JuMP é uma maneira de usar Julia como um **solver matemático**, transformando operações que a princípio seriam complexas de serem programadas do zero em simples comandos que declaram as variáveis, os parâmetros e a faixa em que eles podem variar, e finalmente chamando a função **"optimize!"** para que sejam dados os resultados. Pelo que foi entendido, JuMP é uma espécie de biblioteca com funções matemáticas para facilitar os trabalhos de otimização.

### 3. O PowerModels.js e o PWF.js
Através das funções do JuMP, mais bibliotecas são criadas com os mais diversos objetivos. A **PWF,js** por exemplo é responsável por transformar um tipo de arquivo lido pelo software **ANAREDE** em um formato que possa ser trabalhado em Julia apropriadamente. Isso é importante pois esses dados são linhas de dados que descrevem o SIN inteiro, desde barras até equipamentos da rede, como bancos shunt, tapes de transformadores, etc. Após essa tradução de formato, usamos **PowerModels.js**, uma biblioteca que possui uma série de funções para modelar sistemas elétricos de potência. Com ela podemos modelar geradores com seus dados de operação e analisar o consumo de cargas em diferentes cenários, onde cada um dos parâmetros é definido previamente e os resultados são calculados para dar os valores de quaisquer variáveis declaradas.
